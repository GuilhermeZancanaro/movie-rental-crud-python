# A simple Movie Rental Management System developed in Python as an academic project.

The main goal of this project was to practice CRUD operations, Object-Oriented Programming (OOP), and fundamental Python concepts.

 About the Project:<br>

This project simulates a basic movie rental store system, allowing users to manage a collection of movies through a simple command-line interface.

  Features:<br>
    Add new movies with title, genre, and release year<br>
    List registered movies<br>
    Update/edit movie information<br>
    Remove movies<br>

  Technologies:<br>
    Python<br>
    Object-Oriented Programming (OOP)<br>
    CRUD Operations<br>
    Lists and Data Structures<br>
    Command-Line Interface (CLI)<br>
